## 🚀 What Is This?

Bruhswer is a hardened web browser for Windows based on Microsoft Edge. It locks down network access, quarantines downloads, and runs in disposable sessions. When it can enforce a security rule, it does—and when it can't, it honestly tells you *NOT ENFORCEABLE*. No guessing, no hidden telemetry, just a safer way to browse.

## 🔍 Why Use Bruhswer?

- **Hardened by default** – blocks tracking, telemetry, and unwanted connections.
- **Fail-closed startup** – if something goes wrong, the browser won't start unsafely.
- **Firewall-scoped LAN blocking** – stops apps from accessing your local network without permission.
- **Download quarantine** – every download is sandboxed until you approve it.
- **Disposable sessions** – no history, no cookies, no traces after you close.
- **Honest enforcement** – see what's working and what isn't with clear status messages.

## 🤔 Troubleshooting

- **Bruhswer won't start** – Make sure Microsoft Edge is installed. Bruhswer uses it as a base.
- **Firewall blocking** – You may need to allow Bruhswer through Windows Firewall manually.
- **Slow startup** – First run takes a few seconds. Be patient.
- **Error says "NOT ENFORCEABLE"** – This is normal for some configurations. Bruhswer still works fine.
